# Pausa

Blog de psicología cercano y accesible, orientado especialmente a adolescentes y adultos jóvenes.

## Web pública

[Abrir Pausa](https://pausa-psicologia-joven.luis-delolmo.chatgpt.site)

El repositorio también incluye un workflow preparado para publicar en `https://l0c84.github.io/psicoblog-pausa/` cuando GitHub Pages se habilite con **GitHub Actions** como fuente.

## Desarrollo local

```bash
npm install
npm run dev
```

La carpeta `public-site` contiene la versión estática desplegada automáticamente mediante GitHub Pages. La aplicación fuente está en `app`.
