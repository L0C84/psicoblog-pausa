# Pausa

Blog de psicología cercano y accesible, orientado especialmente a adolescentes y adultos jóvenes.

## Web pública

[Abrir Pausa](https://l0c84.github.io/psicoblog-pausa/)

## Desarrollo local

```bash
npm install
npm run dev
```

La carpeta `public-site` contiene la versión estática desplegada automáticamente mediante GitHub Pages. La aplicación fuente está en `app`.
